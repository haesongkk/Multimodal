# 고양이 V2 게임용 파일

머리와 몸통이 같은 전방을 향하는 정측면 참조 이미지로 VARCO에서 다시 생성한 뒤 Blender에서 좌우 메시 대칭, 웨이트 정리, 경량화와 내보내기를 수행했습니다. VARCO 플로우의 결과는 후처리 이전 버전이며 이 폴더의 파일이 최종 보정본입니다.

## 사용 파일

- `Cat_Game_LOD0_Walk.fbx`: 게임 엔진용 리깅 및 걷기 애니메이션, 텍스처 포함.
- `Cat_Game_LOD0_Walk.glb`: 동일한 기본 LOD의 리깅 및 걷기 애니메이션.
- `Cat_Game_LOD1_Walk.glb`: 원거리용 경량 LOD, 동일한 29본 스켈레톤 사용.
- `Cat_Game_LOD0_Standing.glb`: 대칭 기준 자세의 정적 메시. 스킨/애니메이션 미포함.
- `Cat_Game_Source.blend`: 수정 가능한 메시, 리그, 애니메이션 및 숨겨진 LOD1. 초기 표시를 위해 리그를 Rest Position으로 저장했습니다. 애니메이션 확인 시 리그를 Pose Position으로 전환하세요.
- `Cat_BaseColor_1K.png`: 단일 컬러 아틀라스. sRGB로 사용합니다.
- `Preview/`: 최종 정지 모델의 정면, 측면, 사선 렌더.
- `WalkPreview/`: 걷기 애니메이션 검수 렌더.
- `VALIDATION.json`, `Cat_Game_LOD0_Walk.export_check.json`: 실제 메시/내보내기 검사 결과.

## 사양

| 항목 | LOD0 | LOD1 |
|---|---:|---:|
| 삼각형 | 5,456 | 1,856 |
| 위치 기준 정점 | 2,730 | 930 |
| 재질 슬롯 | 1 | 1 |
| 컬러 텍스처 | 1024 × 1024, 1장 | 동일 아틀라스 |
| 본 수 | 29 | 29 |
| 정점당 최대 본 영향 | 4 | 4 |

로우폴리의 각진 면 법선을 유지하므로 실제 GPU 정점은 면 경계에서 분리됩니다. LOD0 GLB의 POSITION 정점은 16,364개입니다. 표의 위치 기준 정점 수와 구분해야 합니다.

원래 V1의 약 74,688개 삼각형 대비 LOD0는 약 92.7% 적습니다. PBR 노멀/ORM 맵과 투명 재질을 제거하고 불투명 컬러 재질 하나로 구성했습니다. 그림자나 추가 패스까지 포함한 전체 드로콜을 1회로 보장하는 의미는 아닙니다.

## 자세와 검증

- 기준 자세에서 고개를 옆으로 돌리지 않고 얼굴과 몸통의 전방을 일치시켰습니다.
- 음의 X 쪽 메시를 양의 X 쪽으로 미러링했습니다. 텍스처 UV도 대응 면을 복사해 좌우 외형과 무늬를 맞췄습니다.
- 꼬리는 중앙에서 시작하는 단일 꼬리입니다.
- 편집 메시의 좌우 최대 위치 오차는 약 3.73e-9, GLB 재수입 후 오차는 약 4.94e-7입니다.
- 위치 기준으로 용접한 메시의 열린 경계와 비정상 연결은 0개입니다.
- 좌우 웨이트를 미러링하면서 `.L`/`.R` 본을 교환하고 최대 4개 영향으로 정규화했습니다. 웨이트가 없는 정점은 없습니다.
- 작은 발이 발가락 본에서 찌그러지지 않도록 발끝 웨이트를 단순화했습니다.
- 걷기의 루트 높이를 프레임별로 보정했습니다. 재수입한 주요 검수 프레임의 최저 발 높이는 부동소수점 오차 범위에서 바닥 0입니다. 발의 전후 미끄러짐까지 IK로 고정한 애니메이션은 아닙니다.
- GLB 재수입에서 메시 1개, 프리미티브 1개, 재질 1개, 텍스처 1개, 스킨 1개, 애니메이션 1개를 확인했습니다. Blender의 glTF 임포터가 본 표시용으로 만드는 Icosphere는 실제 GLB 메시 개수에 포함되지 않습니다.

## 게임 엔진 적용

4족 전용 Generic/Skeletal 리그로 사용하세요. 인간형 Humanoid 리타기팅 대상이 아닙니다. LOD0와 LOD1은 별도 파일이므로 엔진의 LOD 설정에서 연결해야 합니다. 전방은 Blender -Y, glTF +Z이며 FBX는 임포트 설정에 따라 축이 변환됩니다. 크기와 바닥 피벗도 엔진에서 확인하세요.

타깃 기기, 화면 크기, 동시 등장 수에 대한 엔진 성능 측정은 수행하지 않았습니다. 실제 프로젝트에서 LOD 전환 거리, 텍스처 압축과 밉맵, 그림자 거리 및 스키닝 비용을 확인해야 합니다. 이 파일만으로 모든 환경의 성능을 보장하지는 않습니다.
